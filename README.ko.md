# Wilson

*[→ Read in English](README.md)*

4인 팀 프로젝트 — 생존/탈출 시뮬레이션. Unity 게임제작 부트캠프 1차 팀 프로젝트 (2025.06 ~ 2025.07).
Unity · C# · PC, 3인칭 프리룩 뷰.

## 이 리포에 대해

전체 팀 Unity 프로젝트에서, git 커밋 기록을 기준으로 **내가 작성/관여한 C# 스크립트만 추출**한 리포입니다.

전체 프로젝트(지형·식생·음식 소품·스카이박스 등 유료 Unity 에셋 스토어 패키지 포함)는 private 리포에 있습니다. 이 리포에는 그 에셋들과, 팀원이 전담한 스크립트(리듬게임·퍼즐 미니게임, NPC 행동 및 먹이창고 관리 등)는 제외했습니다. 아래의 플레이어 아이템·인벤토리 시스템은 제가 만든 부분입니다.

- `Scripts/` — 게임 전반의 기능 스크립트: 낮/밤 사이클 및 라이팅, 환경 위험요소·상호작용물(낙석, 돌풍, 제작대, 통발), 아이템·인벤토리, 플레이어 컨트롤러, UI
- `Scripts/_Prototype/` — 팀의 최종 아이템 시스템이 나오기 전, 혼자 만들어본 초기 아이템 시스템 프로토타입

## 팀 구성 & 담당 역할

- 팀 인원: 4명
- 담당: **전체 기획 및 개발 총괄**

프로젝트를 총괄한 입장이라 위 시스템 대부분에 제 커밋이 걸쳐 있습니다 — 한 줄 한 줄 전부 혼자 짠 것은 아니고(공용 파일은 팀원도 함께 수정) 제가 주도했거나 직접 구현/리뷰한 작업을 반영합니다.

이 리포는 그대로는 Unity에서 열리거나 빌드되지 않습니다(씬, 프리팹, 서드파티 에셋이 빠져 있음).
